## 印刷前チェック(現物合わせ)

1. **モバイルバッテリー実寸** → `PB_W`(幅・既定62) / `PB_T`(厚・既定24) を実測値+1mmに
2. **カメラ基板の穴ピッチ** → `CAM_PITCH`(既定28=Arducam IMX291) を実測に
3. 変更したら該当SHOWのみ再レンダリング:
   ```
   openscad -o v2/orange/jacket_shell_v2_x1.stl -D "SHOW=1" torso_v2.scad
   ```

## 組立(要約 — 詳細は設計doc)

裾: フットベース(テープorM3)→底板 → RDK X5をレールへ・バッテリーをトレイへ →
SG90をブラケットへ(M2×2)→デッキ裏へ(M3×2) → デッキを柱4本へ(M3×4) →
ブレッドボード(ESP32-S3ごと)を枠へ → ロープ: 腕穴→デッキφ8穴→ホーン先端
(**ホーン12時=腕下げ・内側回し=引き**。左右逆・ESP32で反転) →
カメラ基板(M2×4)+赤ベゼル → スピーカーを座へ結束 → リッド→襟→頭
