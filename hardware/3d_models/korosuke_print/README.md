# korosuke_print — 印刷用マスター(色分割・電子部品統合)

観賞用`exterior/`を、**実際に刷って組んで電子部品が収まる**外装に再設計したもの。
Webリサーチ(2026-06-25, Wikipedia/pixiv百科/Fandom/公式グッズ)反映済み。

## 設計の柱
1. **色ごとにパーツ分割** — 単色プリンタでもフィラメント交換だけで原作配色
2. **GC9A01目ディスプレイ統合** — 顔に窓φ33+モジュールポケットφ37.6、白ベゼルφ50
   (「目はライトにもなる」公式設定あり=発光目はキャラ準拠!)
3. **RDK X5ケースベイ** — 胴内に縦置きレール(91.4×62.4×27.1+遊び)、背面ハッチでポートアクセス
4. **ESP32-S3トレイ** — 後頭部内壁、首穴φ46でケーブルを胴へ
5. 全パーツ壁3mm中空・ピン/リップ位置決め・平置き印刷向き
