Korosuke
コロ助

An on-device interactive animatronic on the D-Robotics RDK X5 — it sees, listens, thinks, talks (JP / EN), and emotes. 100 % on-device, no cloud.

An open-source, fan-made robot tribute to Korosuke (コロ助) — the clockwork robot from the classic Japanese manga / anime Kiteretsu Daihyakka, built by the boy-inventor Kiteretsu.

「ワガハイはコロ助ナリ！」  — "I am Korosuke!"
On-device architecture01

One RDK X5 owns cognition; an ESP32-S3 drives the body

A ~46 cm Korosuke — perception, speech, LLM, voice & expression, all on the board. No cloud, no API keys.
