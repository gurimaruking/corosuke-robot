# 5分発表 原稿(日本語) — 「ワガハイはコロ助ナリ！」

> 4分トーク + 1分デモ。英語版: [talk_5min_script_en.md](talk_5min_script_en.md) / スライド: [talk_5min.html](talk_5min.html)

## [0:00] スライド1 — タイトル(30秒)

みなさん、こんばんは！今日は参加させていただきありがとうございます。
東京から参加の uecken です。
これは私の**初めてのロボット**——**コロ助**です！
アニメ『キテレツ大百科』に登場するからくりロボットです。
今日のメッセージはシンプルです。**「誰でもロボットを作れる時代が来る」**。
その理由をお見せします。

## [0:30] スライド2 — はじめに(35秒)

コロ助は、藤子・F・不二雄先生の『キテレツ大百科』でキテレツが作る**相棒ロボット**です。
私たちのコロ助は、秋葉原のロボットコワーキングスペース「**ロボスタディオン**」によるファンメイドロボット。
頭脳は **D-RoboticsのRDK X5、1枚だけ**です。
機構も電子もソフトも、**AIと一緒に設計**しました。
見る・聞く・考える・話す・表情する——**すべてボードの上だけ。クラウドなし。**
日本語と英語の両方を話せます。

## [1:05] スライド3 — 背景(35秒)

少し背景を。私は**無線のエンジニア**で、ロボット製作は今回が初めてです。
ある日、店長の**村田さん**が「**コロ助を作らないか！**」と声をかけてくれました。
後日Discordを見てそれを思い出し、秋葉原のロボスタディオンへ。
3Dプリント部品を分けてもらって、作らせてもらいました！
この写真は、初めて頭を胴体に載せた「**頭の装着の儀**」です🎉
デザインは**ディズニーのオラフロボット**と**Open Duck Mini**を参考にしています。

## [1:40] スライド4 — ハードウェア(35秒)

ハードウェアです。**中心にいるのはRDK X5**。
視覚・音声認識・対話・発声——主要機能はぜんぶこの1枚が担当します。
カメラは**マイク兼用**。
目と腕は、USBでつないだ**1台のESP32-S3経由**で制御します。
特別なのは**サーボの電源だけ**——**1アンペアを超える**ことがあるので、**別のLiPoバッテリー**から取っています。
スピーカーは小型化のために**I2Sアンプモジュール**を使用。
**専用基板なし、シンプルな配線だけ**です。

## [2:15] スライド5 — ソフトウェア(35秒)

ソフトは「**brain**」という1つのプログラムです。
**聞く**——声が文字になる。
**考える**——小さなローカルLLM、TinySwallow 1.5Bが返事を作る。
**話す**——Open JTalkの声で。
**見る**——AIチップの**BPU**が毎秒約20フレームで人を見つけ、**目が人を追いかけます**。
そして**動く**——brainがESP32-S3に指示して、**8種類の目の表情**と**腕**を動かします。
考えるのに5〜10秒かかるので、その間は「**考え中の目**」になります。
このWebモニタで全部リアルタイムに見えます。

## [2:50] スライド6 — 製作過程(40秒)

製作です。3Dパーツは**村田店長がAIと共同製作**——データは全部リポジトリにあります。
頭は半球2つ。胴体にすべてが収まります。
腕は輪っかに紐を通した「**ロープアーム**」——サーボが紐を引くと腕が上がる仕組みです。
配線はリポジトリの資料どおり。
そしてソフトは？ **AIに書いてもらいました。**
私は部品を配置して、デバッグする——**「AIの目と手」になった**わけです。
道具は3Dプリンタ、マジックテープ、紐、結束バンド。**きっとどこのメイカースペースにもあるはずです！**

## [3:30] スライド7 — あとがき(30秒)

かかった時間は**約30時間**——印刷15時間、電子とソフトで15時間です。
AIを使えば、小さめのロボットなら**5時間くらい、1日でカスタムロボット**も手が届きます。
すべて**GitHubでオープンソース**です。
これが私のメッセージ——**「誰でもロボットを作れる」**。
では、本人に会ってもらいましょう。**コロ助、あいさつナリ！**

## [4:00] スライド8 — デモ(60秒)

1. 「**コロすけ！**」→ 目が見つけて追いかける *(5秒)*
2. 「こんにちは！元気？」 *(5秒)*
3. 考え中の間に: 「いま考え中です——ローカルLLMがボード上で動いています。これが**考え中の目**です」 *(5〜10秒)*
4. 「〜ナリ！」の返事 *(10秒)*
5. 手を挙げる → **腕を振り返してくれる** *(10秒)*
6. 電源ボタン → 「おやすみコロ助」→ **✕✕目**。「目が✕✕になったら電源を抜いてOK。おやすみのサインです。ありがとうございました！」 *(15秒)*
