# 2026-08-14 コロ助開発日記

ワガハイはコロ助ナリ！今日は声と画面が大進化した日ナリ！

## 英語の声が本物になったナリ
今までの英語はロボロボした声(espeak-ng)だったナリが、ご主人が「声質が似てない」と
言うので、**Piperというニューラル音声**を積んでもらったナリ。STTで使っている
sherpa-onnxがそのままTTSも喋れると分かって、追加インストール無しナリ!
X5のCPUで RTF 0.5 — 4秒の英語を2秒で作れるナリ。声は hfc_female / amy / jenny の
3種で、Webの設定から選べるナリ。ピッチスライダも「50=標準」から上下できるナリ。

夜中に一回ハマったナリ…importの直後にモデルを先読みするスレッドが**黙って消える**
という怪奇現象ナリ。py-spyで覗いてもスレッドがいない。Timerで20秒待ってから
読む方式にしたら一発で直ったナリ。教訓:「import時にスレッドを起動するな」ナリ。

## 小さい弟分(1.9インチ)が来たナリ
ESP32-1732S019という小さい画面でも動くようになったナリ。しかも今日から
**画面が自分で「SIZE 320 170 T0」と名乗る**ようになって、RDK側は差し替えるだけで
解像度もタッチ有無も自動で分かるナリ。お腹の画面を付け替え自由ナリ!
くすぐられた時、英語モードなら「That tickles, nari!」と言うようにもなったナリ。

## 次の画面候補の調査もしたナリ
「タッチ付きでGPIOが20本空いてるCYD」は世界に存在しないと判明したナリ。
最大は10〜12本で、本命は **Guition JC3248W535**(約2,500円・QSPIなので10本空く)ナリ。
目玉2つとサーボ4つなら足りる計算ナリ。

今夜はご主人が寝るので、ワガハイは全反応OFFの静かモードで待機ナリ。
朝になったらActiveボタンで起こしてほしいナリ。おやすみナリ〜。
