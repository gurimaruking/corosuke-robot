# ミニコロ助 — ESP32-S3 単体 設計書

**完全オフライン**で動く手のひらサイズの「コロ助」。RDK X5 を使わず **ESP32-S3 1枚**で
目の表情・なで反応・顔検出・「〜ナリ」音声までを完結させる派生機。
本体（[stage2_design.md](stage2_design.md)）の資産を **流用中心**で再構成する。

> 決定日: 2026-07-29 / 方針: 完全オフライン（no cloud・ネット不要）

---

## 1. スコープ（確定）

| 項目 | 決定 |
|------|------|
| しゃべり方式 | **完全オフライン**。LLM/STT/TTS は載せない（S3では不可能）。事前生成した「〜ナリ」WAV を再生 |
| 搭載機能 | 目の表情8種 ◎ / なで（タッチ）反応 ◎ / **カメラ顔検出→視線追従** |
| 見る | **あり**（カメラ付きS3ボードを使用） |
| 非搭載（今回） | 会話、音センサ反応（マイクは載るが未使用）、腕サーボ |
| ネット | 一切不要（ボード net不通・no cloud 原則を満たす） |

**S3単体で動かせない物（明示）:** TinySwallow-1.5B LLM / sherpa-onnx STT /
Open JTalk・VOICEVOX TTS。いずれも RDK/PC の CPU 前提。ミニ版は声を**事前生成**で回避する。

## 2. ハードウェア

### 2.1 ベースボード（推奨）
**Elecrow ESP Terminal 3.5"（OV2640 同梱）**

| 項目 | 実機仕様 | 備考 |
|------|----------|------|
| MCU | ESP32-S3 / 16MB Flash / 8MB PSRAM | 目描画＋顔検出＋音声に十分 |
| 画面 | 3.5" 320×480 **ILI9488** SPI TFT | 1枚に左右2目を描く |
| タッチ | 静電容量式 | 「なで」＝画面タッチに割当 |
| カメラ | **OV2640 2MP 同梱** | 顔検出（ESP-WHO/esp-dl） |
| マイク | MEMS マイク搭載 | 今回未使用（将来の手拍子反応に流用可） |
| 音声出力 | **ブザーのみ**（アンプ/SP無し） | ⚠️ 音声には別途 I2S アンプが必要 |
| 拡張 | Crowtail×6（2×Analog / 2×Digital / 1×UART / 1×I2C）, SDスロット, LiPo | I2S は空きGPIOへ |

### 2.2 追加部品（買い足しほぼゼロ）
- **MAX98357A ＋ 小型スピーカー**（在庫あり）— I2S で増設。**ブザーでは「〜ナリ」音声は鳴らせない**ため必須
- microSD（音声クリップ格納、小容量で可）
- Elecrow ESP Terminal 3.5" 本体（要購入・$40前後）

### 2.3 配線メモ（ボード到着後に確定）
- I2S(MAX98357A): BCLK/LRCLK/DIN の3本を Digital Crowtail の空きGPIOへ。実ピンは Elecrow pinout で確定する。
- 音声とカメラ(DVP)・LCD(SPI)・タッチ(I2C) のGPIO衝突がないことを配線時に確認。

## 3. ソフトウェア構成（流用マップ）

| ミニ版の要素 | 元ネタ | 作業量 |
|---|---|---|
| 表情8種の描画 | `firmware/corosuke_eyes/src/main.cpp` `renderEye()` | 流用。丸型2枚→単画面に2つ描く座標変更 |
| まばたき/視線補間/アイドル | 同 `loop()` | ほぼ流用 |
| ディスプレイ駆動 | LovyanGFX（GC9A01→**ILI9488**へパネル差替） | ドライバ設定変更 |
| なで検知 | 同 touchRead(GPIO6) | **静電タッチスクリーン**へ置換 |
| 台本・感情・「〜ナリ」 | `ros2_ws/.../personality.py` `EXPRESSION_KEYWORDS`/`EYE_EMOTION` | 定型セリフを C++ テーブル化 |
| 声質 | personality.py `OJ_FM=9 / OJ_A=0.40 / OJ_R=1.12` | PC側 Open JTalk で WAV 事前生成→SD |
| 顔検出→視線 | 新規（ESP-WHO human_face_detect） | S3完結。bbox中心→`gaze` に写像 |

- 目の描画は**自作コード**（RoboEyes 不使用）＝ stage2 R6 の GPL 懸念なし。
- 感情は本体と同じ 8 種（neutral/happy/happy2/sad/angry/surprised/sleepy/thinking/✕✕）。

### 3.1 自律ふるまいエンジン（新規・S3側）
本体では RDK が感情を決めていたが、ミニ版は S3 が自分で決める：
- アイドル：まばたき＋視線ゆらぎ（既存流用）
- 顔を検出：その方向へ視線→数百ms後に happy ＋ 挨拶WAV
- なで（画面タッチ）：happy ＋ 反応WAV（1.2s デバウンス、既存踏襲）
- ランダム：たまに thinking / sleepy など小芝居＋短いWAV
